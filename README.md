Take-home Test – Data Analyst (Sales & Profit Performance)
📌 Project Overview


Proyek ini berfokus pada analisis performa penjualan, profitabilitas, dan inventory menggunakan data retail inventory serta penyajian hasilnya dalam dashboard interaktif berbasis Streamlit.

Tujuan utama project ini adalah:

Menganalisis revenue & profit performance

Mengidentifikasi kategori, produk, dan brand unggulan

Mendeteksi ketidakefisienan inventory (overstock vs sold items)

Memberikan insight dan rekomendasi bisnis yang actionable

Project ini dibuat sebagai take-home test / portfolio project untuk posisi Data Analyst / Data Scientist dengan pendekatan business-driven analytics.
